Solutions I've delivered

Real things I've shipped and run in production — not tutorial projects. Hover around, everything reacts.

/ 01 Browser Extension · Production

One-Click Form Automation Suite

Built and deployed Chrome extensions for three applications that automate multi-page form filling with a single click — integrated into a centralized system with automatic initialization on launch, a clean UI, real-time error handling, and update notifications.

Chrome APIsManifest V3Content ScriptsMessaging APIs

Problem

Users across three separate applications had to manually re-enter the same data across multi-page forms every time — slow, repetitive, and error-prone at scale.

Approach

Built Chrome extensions on Manifest V3 with content and background scripts talking over the messaging APIs, wired into a centralized system that auto-initializes on launch so every app gets the same one-click fill behavior, real-time error handling, and update notifications without separate setup.

Result

Multi-page forms now fill in a single click across all three applications, cutting repetitive manual entry and reducing input errors for every user of the centralized system.

/ 02 Business Automation · Production

Lead Generation & Publishing Workflows

Designed n8n automation workflows for lead generation integrating email, WhatsApp, and LinkedIn, plus automated YouTube and LinkedIn publishing pipelines — improving operational efficiency at zero recurring cost.

n8nWhatsApp APIEmailLinkedInYouTubeTelegram

Problem

Lead follow-up and content publishing were manual, scattered across email, WhatsApp, LinkedIn, and YouTube — and every new lead, invitation, or video meant repeating the same steps by hand.

Approach

Designed n8n workflows that integrate email, WhatsApp, and LinkedIn into a single lead-generation pipeline; a WhatsApp workflow for sending company event invitations; and content pipelines that generate and publish to YouTube and LinkedIn automatically — with guardrails and a Telegram approval step before anything goes live, all on free-tier tooling.

Result

Leads get captured and followed up automatically, event invitations go out over WhatsApp without manual sending, and content publishes to YouTube and LinkedIn with a human approval checkpoint in between — all running at zero recurring cost.

/ 04 Cloud & DevOps · In Progress

DigitalOcean → AWS EKS Migration

Leading migration of multiple applications to AWS EKS: Dockerizing services, building CI/CD pipelines, deploying with high availability and scalability, integrating Trivy & SonarQube security scanning, centralized OpenSearch logging, OpenVPN, and Prometheus / Grafana / CloudWatch dashboards.

AWS EKSDockerCI/CDGrafanaOpenSearch

Problem

Multiple applications were running on a single DigitalOcean droplet — a setup that limits high availability, scalability, and the security/observability tooling a growing product needs.

Approach

Leading the migration to AWS EKS: Dockerizing each service, building CI/CD pipelines around them, and standing up supporting infrastructure — VPC, RDS, ElastiCache, and S3 — alongside Trivy and SonarQube security scanning, OpenVPN access, centralized OpenSearch logging, and Prometheus/Grafana/CloudWatch monitoring.

Result

In progress: moving toward a highly-available, horizontally scalable deployment with centralized logging, security scanning, and real-time monitoring in place of a single point of failure.
